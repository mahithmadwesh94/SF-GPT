# SF-GPT — AI-Powered Salesforce Assistant

A conversational AI assistant built on OpenAI GPT-4o-mini, 
specialised in Salesforce — Sales Cloud, Service Cloud, 
Experience Cloud, and Financial Services Cloud.

Built by a 7-year Salesforce veteran transitioning into AI engineering.

## Stack
- Python 3
- OpenAI API (gpt-4o-mini)
- FastAPI (coming next)
